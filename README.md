# TabAgent

用自然语言指挥 AI 操作网页：点击、填写、提取、跨标签页汇总。把“复制、粘贴、切换标签页”的循环交给 AI，让浏览器变成任务执行器。

一套 TypeScript 代码，基于 [WXT](https://wxt.dev)，分别构建 Chrome/Edge（Manifest V3）和 Firefox（Manifest V2）版本；Chromium 内核浏览器可使用 Chrome 版。Safari 还需在 Mac 上转换和验证。

## 能做什么

- **读页面**：把当前页面整理成带编号的可交互元素列表和正文；长文支持按偏移量分段读取，附上来源网址。
- **搜索网页**：直接输入“搜索 AITransX 相关页面”，即可搜索、读取结果并返回来源链接。支持 Bing、Google、百度，无需搜索 API Key；在新标签页也能发起，只读模式可用。
- **操作页面**：点击、输入（兼容 React/Vue 受控输入框）、选择下拉框、按键、悬停、滚动、前进后退、打开网址。
- **提取数据**：按 CSS 选择器批量抓取列表和表格。
- **跨标签页**：选择本次任务允许访问的页面，把多个页面的信息汇总成一张表；关闭跟随时无需切换页面。
- **操作模式**：默认只读，可搜索并打开搜索结果。切换到“操作需确认”后，点击、填写、滚动、导航和其他标签页修改等动作会展示确认卡，批准后执行；页面或目标元素变化会要求重新读取和确认。
- **历史会话**：记录保存在本机，支持切换、恢复上下文与删除；后台重启时会标记中断任务，等待新的用户指令。
- **连接诊断**：设置页可测试模型的工具调用能力，区分鉴权、模型/接口、限流、网络和超时问题。
- **图片识别**：为支持图片的模型开启“图片识别”，即可按需截取当前网页，分析可视区域中的图片、图表、Canvas 和布局。文字和表格仍优先读取页面结构。

## 安装（开发者模式加载）

先构建（开发与完整测试使用 Node.js 22.18+）：

```bash
npm install
npm run build:all      # 生成 .output/chrome-mv3、edge-mv3、firefox-mv2
```

| 浏览器 | 步骤 |
| --- | --- |
| Chrome / Brave / Opera 等 | 打开 `chrome://extensions` → 右上角打开“开发者模式” → “加载已解压的扩展程序” → 选 `.output/chrome-mv3` |
| Edge | 打开 `edge://extensions` → 左侧打开“开发人员模式” → “加载解压缩的扩展” → 选 `.output/edge-mv3` |
| Firefox | 打开 `about:debugging#/runtime/this-firefox` → “临时载入附加组件” → 选 `.output/firefox-mv2/manifest.json`（临时加载，重启浏览器后需重新加载；长期使用需要提交到 AMO 签名） |
| Safari | 需要一台装了 Xcode 的 Mac：`npm run build:safari`，然后 `xcrun safari-web-extension-converter .output/safari-mv3`，用 Xcode 运行生成的工程，再在 Safari 设置 → 扩展中启用 |

加载后：

1. 点工具栏上的 TabAgent 图标打开侧边栏（Safari 没有侧边栏，会弹出一个小窗口）。
2. 点“设置”，填写 API Key：
   - **Claude**：填写 API Key 和账号实际可用、支持工具调用的模型名，也可填写兼容接口地址；预填模型名不代表当前服务一定提供该模型。
   - **OpenAI 兼容接口**：填接口地址、Key 和模型名，支持 OpenAI、DeepSeek、通义千问、Kimi、智谱、OpenRouter、本地 Ollama 等（模型需支持工具调用）。
3. 可点击“测试连接”验证当前填写的配置。测试会发送固定的小型工具调用请求，不包含网页内容，也不会自动保存设置；测试通过后点击“保存设置”。
4. 在侧边栏选择只读或操作模式，按需选择任务页面，再输入指令。例如对比多个商品页时，先在“当前页面”按钮中选择这些页面。

API Key 只保存在本机浏览器的插件存储里，插件直接从浏览器调用模型服务，不经过其它服务器。

## 使用小提示

- 侧栏顶部在执行中显示真正的操作目标；默认任务范围为发送时的当前普通网页，也可以选择最多 50 个页面。未选中的已有页面不能通过工具访问；搜索或确认新建的标签页会加入本轮范围。
- **跟随任务页面默认开启**：搜索、打开结果或处理其他任务页面时自动展示目标标签页，侧栏同时显示当前动作和页面。页面卡旁的“跟随”按钮可随时关闭，切到“后台”执行；偏好会保存在本机，下次打开侧栏仍然生效。跟随只改变页面的显示，不扩大任务范围，也不代替操作确认。
- 搜索会新建标签页，每个任务最多新建 8 个检索页面，任务范围总数不超过 50。可指定“用 Google 搜索…”或“用百度搜索…”，默认使用 Bing。新标签页、设置页等无法读取内容，但不影响发起搜索。
- 任务成功完成后，默认关闭本轮已读的临时检索页；跟随时回到原页面。原有页面、主动打开的网址、手动保留或操作过的页面，以及加载失败、验证码页面会留下；停止或失败的任务不自动清理。执行时可点击“保留”，也可在任务范围中关闭“任务完成后关闭临时页”。
- 回复下方的“参考页面”汇总本轮实际读取的网页，支持单页或全部重新打开，并随会话历史和导出保存。重新打开恢复的是网页链接，不恢复当时的表单、滚动位置或页面快照。
- 网页正文就绪后即可读取，无需等待图片和广告全部加载。搜索会等待实际结果；遇到网络错误、网站访问权限或验证码时分别提示，验证页不会被当作搜索结果。
- 点击示例会填入指令，确认后再发送；未发送的草稿按会话分别保存在本机，关闭或重新打开侧栏后仍可继续编辑。
- 填表示例会切换到“操作需确认”，跨页对比会引导选择页面。点击顶部页面卡也可调整范围，标签页列表支持搜索标题或网址；已有草稿不会被示例覆盖。
- 多窗口草稿会同步；同时编辑发生冲突时保留本地版本，并提供版本选择，避免旧面板覆盖新内容。
- `Enter` 发送，`Shift+Enter` 换行。任务执行中可以先写下一条指令，按 Enter 不会中断任务；需要中断时点击“停止”。
- 执行步骤可以展开查看参数与结果，回复支持一键复制 Markdown。向上阅读时不会被新消息打断，可点击“回到最新消息”继续跟进。
- 成功完成的执行过程默认收起，未完成步骤保留展开；手动展开的过程不会自动关闭。代码块可单独复制，宽表格支持鼠标及键盘横向滚动。
- 回复会逐段显示；停止或断流时保留已收到的文字并标注未完成。兼容接口如果返回完整 JSON，仍按完整回复显示；未完成的工具调用不会执行。
- “新对话”会结束当前任务并保留旧会话；顶部历史按钮可打开旧记录及其草稿，删除需要二次确认。后台或浏览器重启后，记录和最近执行摘要会用于恢复上下文，旧审批不会继续执行。需要继续时检查网页后发送新指令。
- 历史支持按标题及消息内容搜索、重命名；当前会话可导出 Markdown 或 JSON。历史按会话分开存储并合并频繁写入，旧记录自动迁移，无需手工处理。
- 只读模式允许搜索、打开本轮搜索返回的链接、读取、提取和等待，不允许修改已有网页。操作模式会展示动作、目标页面、输入内容及确认按钮；拒绝会结束本次任务。停止或切换对话不会撤销已经完成的网页操作。
- 长文每段默认 6000 字，模型可用返回的 `next_offset` 读取后文；单段最多 20000 字。提取结果保留来源网址，页面变化后需要从头重新读取。
- 修改模型服务或连接配置后，下一条指令会使用新的模型连接，并恢复已有对话文字和最近执行摘要。
- 长会话会压缩模型请求中的旧上下文，保留近期目标与工具结果；本地完整历史不会因此被删除。
- 设置页支持密钥显隐、地址与步数校验、未保存提醒，以及 `Ctrl/Cmd+S` 保存；界面随系统切换浅色或深色模式。
- 设置页支持“撤销更改”，恢复上次保存的配置并取消正在进行的连接测试，不自动写入设置。
- 图片识别默认关闭，在对应模型的连接配置中开启并保存。模型必须同时支持工具调用与图片输入；更换模型或接口地址会关闭开关，需要重新开启。“测试连接”只验证连接和工具调用，不验证图片能力。
- 开启后可直接输入“看一下当前页面的图表”或“分析这个页面的显示问题”。只截取任务范围内、当前正在浏览的网页可视区域；跟随开启时会先显示任务目标，关闭跟随时需手动切换到要截图的页面。截图会压缩后发送给当前配置的模型，每个任务最多两张。
- 截图时需让目标网页窗口保持在前台。使用独立弹窗界面的浏览器时，弹窗占据焦点会阻止截图；当前图片功能优先用于 Chrome、Edge、Firefox 的侧栏界面。
- 截图仅用于紧接着的一次模型请求，不写入本地历史、草稿或导出文件。新的任务会重新观察页面；截图期间停止、切页或跳转会丢弃该次截图。图片识别不提供坐标点击或绕过操作确认。

## 开发

```bash
npm run dev            # Chrome 热重载开发
npm run dev:firefox    # Firefox
npm run compile        # 类型检查
npm run test:vision    # 图片识别与截图边界回归（本地模拟模型）
npm run test:e2e       # 端到端测试：在真实 Chromium 里用本地假模型跑完整流程（需要 Playwright 的 Chromium）
npm run test:diagnostics # 本地模拟接口：鉴权/限流/超时/取消/工具调用诊断
npm run test:features  # 范围和只读限制、审批守卫、长文读取、浏览器重启恢复
npm run test:search    # 新标签页搜索、完整结果链接、范围隔离与取消（模拟搜索引擎及模型）
npm run test:lifetime  # 无调试器的真实 Chromium：40 秒静默模型请求与任务后台存活
npm run test:follow    # 跟随页面、加载中展示、动态关闭、偏好持久化与停止边界
npm run test:references # 临时页清理、手动保留、参考页面与历史重开
npm run test:visual    # 窄屏/短屏、大字号、浅深色和确认卡等布局检查
npm run test:pdf       # 在线 PDF 文字读取边界、可见区域截图及 MIME 检测
npm run test:storage   # 历史迁移、合并写入、失败恢复与删除
npm run test:llm       # 流式响应、断流/取消、工具参数与上下文预算
npm run test:actions   # 动作取消、超时、去重及动态页面语义检查
npm run test:panel     # 双面板草稿、流式界面、历史搜索与导出
npm run test:ux        # 示例引导、键盘/阅读体验、窄屏和设置撤销
npm test              # 类型检查及全部回归（均使用本地模拟模型）
npm run zip:all        # 打包商店用的 zip
```

## 代码结构

```
entrypoints/
  background.ts        后台：打开侧边栏、管理智能体会话
  content.ts           内容脚本：给页面元素编号，执行点击/输入/提取
  sidepanel/           侧边栏聊天界面
  options/             设置页
lib/
  agent.ts             智能体循环：调用模型 → 执行工具 → 回传结果，直到完成
  conversations.ts     本地历史存储、状态恢复与有序保存
  tool-policy.ts       只读工具列表与操作确认策略
  tools.ts             工具定义与执行（标签页、页面操作）
  llm/anthropic.ts     Claude（官方 SDK）
  llm/openai.ts        OpenAI 兼容接口
  llm/diagnostics.ts   连接测试、请求超时与错误分类
  markdown.ts          安全的 Markdown 渲染
  settings.ts          设置读写
tests/e2e.mjs          端到端测试
```

## 已知限制

- 浏览器禁止插件读取或操作内部页面（`chrome://`、扩展商店、新标签页），仍可从这些页面发起搜索，读取新打开的普通网页。
- 搜索依赖所选搜索引擎在当前网络下可访问；遇到验证码或访问限制时需手动处理，或指定其他搜索引擎。
- PDF 尚不支持全文解析、按页提取或本地文件读取。在线 PDF 在浏览器可正常显示、模型支持图片且开启“图片识别”时，可分析当前可见区域；截图不代表已读完整份文件。正文读取和表格提取遇到原生 PDF 会明确提示限制。
- 暂不支持跨域 iframe 内部操作和 Canvas 元素点击；启用图片识别后，可分析当前可见的 Canvas 内容。验证码需要手动处理。
- Firefox 用 MV2 构建（安装即获得网站权限，体验更顺）；Safari 需要 Mac + Xcode 打包。
